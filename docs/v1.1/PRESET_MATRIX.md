# v1.1 权限预设对照

下表是默认继承权限。Scene 内显式 `allow/deny`、全局拒绝、可信 Owner 身份、Provider 状态和 QQ 平台权限会继续决定实际结果；Web Console 显示最终生效值与原因。

| 能力 | 仅观察 | 安全聊天 | 增强对话 | 自主群友 | Owner Agent |
| --- | --- | --- | --- | --- | --- |
| 读取已授权 Scene | 是 | 是 | 是 | 是 | 是 |
| 发送普通消息 | 否 | 是 | 是 | 是 | 是 |
| DSH 搜索与媒体读取 | 否 | 否 | 是 | 是 | 是 |
| 回应、戳一戳、撤回 | 否 | 否 | 是 | 是 | 是 |
| 未被 @ 的群消息触发参与判断 | 否 | 否 | 否 | 是 | 不适用 |
| 群管理写入 | 否 | 否 | 否 | 否 | 不适用 |
| 账号资料与 QQ 空间 | 否 | 否 | 否 | 否 | 需账号页显式授权 |
| Owner 文件/Host 工具 | 否 | 否 | 否 | 否 | 仍需单项授权与 Host Guard |

Owner Agent 只能用于已配置的可信 Owner 私聊。群管理需要对对应 Scene 手动允许，并由 NapCat/QQ 平台再次拒绝无权操作。`custom` 只是界面编辑状态，不是后端权限模式。手动调整后保留其他字段；重新选择命名预设会重置原有覆盖与行为参数。

行为参数默认值：

| 预设 | 合批静默窗口 | 续聊等待上限 | 自主接话冷却 | 近期上下文上限 |
| --- | ---: | ---: | ---: | ---: |
| 仅观察 | 0 秒 | 0 秒 | 0 秒 | 20 条 |
| 安全聊天 | 5 秒 | 30 秒 | 0 秒 | 20 条 |
| 增强对话 | 10 秒 | 30 秒 | 0 秒 | 20 条 |
| 自主群友 | 12 秒 | 30 秒 | 15 秒 | 20 条 |
| Owner Agent | 10 秒 | 30 秒 | 0 秒 | 20 条 |

“参与活跃度”随请求传给当前对话模型作为判断提示；它不创建定时主动发言。静默窗口有最长等待上限，续聊等待及上下文上限在 QQ 执行路径约束。
